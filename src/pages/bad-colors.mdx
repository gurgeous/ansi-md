ANSI 16 colors can be literally anything. Each palette has slots for `theme fg`, `theme bg`, `black`, `red`, `green`, `yellow`, `blue`, `magenta`, `cyan` & `white`. There's also a tricky `reverse` ansi escape code which swaps fg/bg, so it is technically possible to use `theme bg` as the fg. Confusing!
