---
title: Recommended CLI Apps
---

Well, as you might expect I enjoy a wide variety of cli apps myself. I install most of these with `brew` or `mise`, and I try to keep my list curated to stuff I actually use. Enjoy.

### Clearly Superior

I think everyone dev should use these, personally.

| app                                              | ⭐ stars | what it does                     |
| ------------------------------------------------ | ------- | -------------------------------- |
| [atuin](https://atuin.sh/)                       | 31.1k   | better shell history, with sync  |
| [bat](https://github.com/sharkdp/bat)            | 60.2k   | `cat` replacement                |
| [delta](https://github.com/dandavison/delta)     | 31.7k   | colorful diff viewer             |
| [doggo](https://github.com/mr-karan/doggo)       | 4.4k    | `nslookup` replacement           |
| [dust](https://github.com/bootandy/dust)         | 12.1k   | `du` replacement                 |
| [eza](https://eza.rocks/)                        | 22.9k   | `ls` replacement                 |
| [fd](https://github.com/sharkdp/fd)              | 44.1k   | `find` replacement               |
| [fx](https://fx.wtf/)                            | 20.6k   | interactive json browser         |
| [ghostty](https://ghostty.org/)                  | 59.5k   | preferred terminal               |
| [gron](https://github.com/tomnomnom/gron)        | 14.5k   | fully expand json for grepping   |
| [just](https://just.systems/)                    | 35.3k   | command runner                   |
| [mise](https://mise.en.dev/)                     | 32.3k   | dev tool manager                 |
| [oh-my-posh](https://ohmyposh.dev/)              | 23.3k   | my prompt                        |
| [ripgrep](https://github.com/BurntSushi/ripgrep) | 67.2k   | `grep` replacement               |
| [sd](https://github.com/chmln/sd)                | 7.3k    | `sed` replacement                |
| [tennis](https://github.com/gurgeous/tennis)     | 785     | stylish terminal tables          |
| [watchexec](https://watchexec.github.io/)        | 7.1k    | run a command when things change |

Many of these pair nicely. For example, I use `mise` to install `just` and use a `just test-watch` rule with `watchexec` to run tests whenever something changes. Once you get used to working this way it's hard to go back. All wrapped in nice ansi color output, of course.
