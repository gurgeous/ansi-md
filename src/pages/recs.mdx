---
title: Recommended CLI Apps
---

Well, as you might expect I enjoy a wide variety of cli apps myself. I install most of these with `brew` or `mise`, and I try to keep my list curated to stuff I actually use. Enjoy.

### Clearly Superior

I think everyone dev should use these, personally.

| app                                              | what it does                     |
| ------------------------------------------------ | -------------------------------- |
| [atuin](https://atuin.sh/)                       | better shell history, with sync  |
| [bat](https://github.com/sharkdp/bat)            | `cat` replacement                |
| [delta](https://github.com/dandavison/delta)     | colorful diff viewer             |
| [doggo](https://github.com/mr-karan/doggo)       | `nslookup` replacement           |
| [dust](https://github.com/bootandy/dust)         | `du` replacement                 |
| [eza](https://eza.rocks/)                        | `ls` replacement                 |
| [fd](https://github.com/sharkdp/fd)              | `find` replacement               |
| [fx](https://fx.wtf/)                            | interactive json browser         |
| [gron](https://github.com/tomnomnom/gron)        | fully expand json for grepping   |
| [just](https://just.systems/)                    | command runner                   |
| [mise](https://mise.en.dev/)                     | dev tool manager                 |
| [oh-my-posh](https://ohmyposh.dev/)              | my prompt                        |
| [ripgrep](https://github.com/BurntSushi/ripgrep) | `grep` replacement               |
| [sd](https://github.com/chmln/sd)                | `sed` replacement                |
| [tailscale](https://tailscale.com/)              | personal network for your boxes  |
| [tennis](https://github.com/gurgeous/tennis)     | stylish terminal tables          |
| [watchexec](https://watchexec.github.io/)        | run a command when things change |
| [zed](https://zed.dev/)                          | preferred editor                 |

Many of these pair nicely. For example, I use `mise` to install `just` and use a `just test-watch` rule with `watchexec` to run tests whenever something changes. Once you get used to working this way it's hard to go back. All wrapped in nice ansi color output, of course.
