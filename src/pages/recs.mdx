As you might expect I enjoy a wide variety of cli apps myself. I install most of these with `mise` or `brew`, and I try to curate this list to stuff I actually use. Enjoy.

#### Apps

I think every dev should use these, personally.

| app                                       | ⭐ stars | what it does                     |
| ----------------------------------------- | :------: | -------------------------------- |
| [atuin](https://atuin.sh/)                |   31k    | better shell history, with sync  |
| github/sharkdp/bat                        |   60k    | `cat` replacement                |
| github/dandavison/delta                   |   32k    | colorful diff viewer             |
| github/mr-karan/doggo                     |    4k    | `nslookup` replacement           |
| github/bootandy/dust                      |   12k    | `du` replacement                 |
| [eza](https://eza.rocks/)                 |   23k    | `ls` replacement                 |
| github/sharkdp/fd                         |   44k    | `find` replacement               |
| [fx](https://fx.wtf/)                     |   21k    | interactive json browser         |
| [ghostty](https://ghostty.org/)           |   59k    | preferred terminal               |
| github/tomnomnom/gron                     |   14k    | fully expand json for grepping   |
| [just](https://just.systems/)             |   35k    | command runner                   |
| [mise](https://mise.en.dev/)              |   32k    | dev tool manager                 |
| [oh-my-posh](https://ohmyposh.dev/)       |   23k    | my prompt                        |
| github/BurntSushi/ripgrep                 |   67k    | `grep` replacement               |
| github/chmln/sd                           |    7k    | `sed` replacement                |
| github/gurgeous/tennis                    |   785    | stylish terminal tables          |
| [watchexec](https://watchexec.github.io/) |    7k    | run a command when things change |

Many of these pair nicely. For example, I use `mise` to install `just` and use a `just test-watch` rule with `watchexec` to run tests whenever something changes. Once you get used to working this way it's hard to go back. All wrapped in nice ansi color output with [banner/warning/fatal](/advanced#bannerwarningfatal), of course.
