The ANSI 16 palette has slots for `theme fg`, `theme bg`, `black`, `red`, `green`, `yellow`, `blue`, `magenta`, `cyan` & `white`. There's also a tricky `reverse` ansi escape code which swaps fg/bg, so it is technically possible to use `theme bg` as the foreground color.

ANSI 16 says that the color is `green`, but if your user installs the Ghostty Spiderman theme it's actually red on screen. Confusing!

The tool below shows what text looks like for ALL the Ghostty themes. Hover to see theme name. As you can tell, there's really no combo that works reliably. If you want a colorful banner, you probably need to use ANSI 256 or truecolor.
