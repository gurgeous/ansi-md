Most CLI apps run for a moment, write some lines, and then exit. Our old friend `ls` (well, github/eza-community/eza) fires itself up, spits out a few lines, and then exits. But there's a whole other category of full blown apps that hang around so you can interact with them. This kind of app is called a **Terminal User Interface**, or TUI for short. A broad definition includes stalwarts like `emacs` or `tmux`, but here I'm mainly focused on newer TUIs that strive for beautiful design and advanced layout.

Disclaimer - I've only written a handful of TUI apps, mostly unreleased. My favorite is probably my RPN calculator [vectro](github/gurgeous/vectro). Also at https://vectro.app.

### TUI Libraries

Every TUI is built on a TUI library. If you think about it, each TUI must include the crude equivalent of a web browser - event loop, layout engine, and widgets. These libs are powerful and complicated. Some of them are a bit like react, with nested components and props. Some use flexbox.
