Behold, my incredible color converter technology. Type in a color as RGB hex and I will find the closest ansi 256 color and the closest tailwind color. Depending on use case I might need one or the other. This tool uses [DeltaE in Color.js](https://colorjs.io/docs/color-difference.html) for calculating perceptual distance (not euclidean).
